# InkSheets viewer, source alignment and playback follow-up

This follow-up is being validated locally. The currently published release is still test.300; update this record after the new release is verified.

## Changes visible to the player

- Large viewer tools use an extended bar and reserve score space. Metronome and tuner remain small floating controls. Starting a recording closes the expanded recorder and leaves live status and Stop accessible.
- Studio can sit on either side. Wide footers put tools and navigation together; narrow phones retain two rows. Dock layout stays constrained and separate from the original full annotation palette and original Fix workflow.
- Leading/following actions stay outside Studio widget scrolling. Lead exposes Message, sharing, group settings and preferred presets; Follow exposes Return, readable following modes and Leave.
- Clean/Mask reuse completed drawing and native mask geometry. Selecting Mask opens the original brush controls. Native path copies preserve their fill rule, including eraser holes.
- Source-based engraving retains individual chord-head locations, glyph bounds, rests, stems/beams, clefs/signatures and notation decorations. Edited pitches/rest positions/durations/marks take precedence over old geometry; reflowed exports retain their normal layout. Existing readings remain available; rereading captures the new metadata and retains corrections.
- Phrase slurs retain repeated wind-note attacks; true ties sustain, including a tie on only one chord pitch. Articulations affect attack/length independently. Mute instructions persist through rests and cancel on open/senza sordino.
- A compact CC0 recorded pack works offline as defaults for trumpet, trombone, clarinet and tenor sax, including a separate straight-muted trumpet. User-provided samples still override defaults. Source gain balancing avoids adding a second large volume jump between soft/loud takes. Sustains have validated crossfaded loops.

## Evidence collected

Complete local regression after the follow-up fixes: **1,105 passed, 78 gated/skipped, zero failures** (core341; music core329+1skip; desktop156+9skips; InkSheets desktop140+68skips; Android InkSheets76; Android InkSlate63). Both Android app variants pass; phone/watch debug packages assemble. The final compact-resource sustain check and package rebuild are performed separately after this run.

- Real source PDFs: Diva119 noteheads, position p95=.00177 staff spaces against native PDF font outlines; Chester162 noteheads, p95=.01568. Width errors negligible. These measurements concern recognized heads, not every recognized musical symbol.
- Synthetic skew/nonuniform staff and page-scale checks cover final overlay polygons, correction precedence and source rest placement.
- Desktop mask benchmark:120 committed strokes and16 live previews, median of3 runs. Historical reconstruction560.4ms; incremental updates11.0ms (51.1× in this fixture); pixel parity checked at6700 points. This is a desktop native-path benchmark, not a physical Android frame-rate claim.
- Twelve-size drawer/recording/real-PDF viewer checks, original annotation/Fix checks, right-side Studio and lead/follow actions are included in the combined regression.
- Recorded-source tests cover finite/unclipped output, all sustain layers held20seconds, and long slur playback without source-length cutoffs. No audio device is opened by the tests.

## Limits

Physical device BLE, pen and audio checks remain necessary. The recorded pack is about17MiB before installer compression and decodes instruments on demand; it does not yet cover euphonium, alto/baritone sax or every other instrument. Those retain synthesized fallback. Sample slurs use crossfades rather than recorded interval-specific legato transitions. No dedicated accent takes are included; accents shape the existing instrument tone. Tremolo/flutter and other specialist sample articulations are not claimed. Existing recognition errors can still produce an omitted/wrong note; alignment does not certify recognition accuracy.

## Rebuilding the free recorded pack

Use Python with numpy. Run `scripts/build_recorded_defaults.py`, then `scripts/package_recorded_defaults.py`. The second step validates loops and balances layers without rewriting original converted WAVs. The shipped pack contains both CC0 licenses, pinned source commits/file hashes, conversion provenance, loop metrics and level-balance data. Sources: https://github.com/sgossner/VSCO-2-CE and https://github.com/sgossner/VCSL .
