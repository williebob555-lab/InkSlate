Existing continuity tests covered synthesized patches without these marks. Add recorded-default clarinet/sax/trumpet renders and long-phrase coverage; retain explicit staccato/breath separation.
3. Band treated any non-null cached reading as complete. Shared PDFs with only the current part read produced empty other-part scores, counted as voices. Check assigned-page completeness, complete unread caches, and exclude empty scores. Broader Band redevelopment remains deferred.
4. MusicStrip removal also removed instrument preloading. Move it to the surviving viewer mount so assigned user patches have a chance to load before first Play.
5. Selecting Mask before drawing leaves masks-only mode with no positive mask. Explicit Clean-on preserved that mode and did nothing. Clean-on in this state must explicitly enable whole Clean; selecting Mask itself must never do so.
