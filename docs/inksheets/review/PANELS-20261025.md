# Settings and editing panels — 25 October 2026

## Implemented

- InkSheets Settings uses a shared responsive category workspace: a sidebar on wide windows,
  horizontally scrollable category chips on narrow windows. The current category is scrolled
  into view. The InkSlate settings layout remains unchanged.
- All original platform settings remain reachable. Desktop groups appearance, saving,
  reading/annotation, personal devices, storage/files, and updates/diagnostics. Android retains
  its existing sections in corresponding groups, including file overrides, autosave, pedal keys,
  storage diagnostics, old companion-file migration, and update channels.
- InkSheets-specific settings separate Library, Controllers, and Music tools. The experimental
  switches, microphone test, sampled instruments and watch controls are retained.
- Song editing separates Details and Parts in one frame. Part assignments retain source/file
  information, searchable instruments, chair, multi-instrument aliases, preview, ordering,
  page arrangement, move/split and deletion. Inclusive first/last page ranges are directly
  editable, validated, and persisted.
- Saving applies individual field deltas so background instrument assignments and newly synced
  ranges survive unrelated edits. Move/split subtasks replace the editor frame; cancelling
  them returns to the draft instead of leaving stacked dialogs.

## QA

`PanelsRedesignTest` covers valid/invalid page ranges, UI validation and saving while a changed
instrument assignment arrives, and assignment/settings layout captures at all twelve UiAudit
sizes. Execution is coordinated by the lead to respect the machine's Gradle job limit.

No real library, audio device, controller, or installed-app settings are used by these tests.
